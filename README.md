# FLIPNext per computer — installatori

Qui si trovano gli **installatori** dell'app FLIPNext per computer (Windows, Mac, Linux).
Questo repository contiene solo i programmi già pronti, **non il codice**.

**Scarica l'ultima versione:** vai su [Releases](../../releases/latest) e scegli il file per il tuo sistema:

| Sistema | File |
|---|---|
| Windows | `FLIPNext-…-win-x64.exe` |
| Mac | `FLIPNext-…-mac-….dmg` |
| Linux | `FLIPNext-…-linux-x86_64.AppImage` |

> Sono versioni di prova, **non firmate**: Windows e Mac possono mostrare un avviso prima di aprirle.
> Se hai dubbi, scrivi a chi ti ha dato il link.

Sito: https://www.flipnext.it
